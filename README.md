🚀 Overview

personal-finance-dashboard is a full-stack web application built to help users track and manage their personal finances.
It provides a dashboard-style interface to visualize expenses, savings, budgets, and analytics with secure authentication.

✨ Features
	•	💸 Expense Tracking – Add, categorize, and view expenses.
	•	📊 Budget Management – Set budgets and monitor spending.
	•	💰 Savings Goals – Track progress toward financial goals.
	•	📈 Analytics & Reports – Visual insights into income vs. expenses.
	•	🔐 User Authentication – Secure login and signup.

🛠️ Tech Stack
	•	Frontend: React, JavaScript, TailwindCSS, Chart.js
	•	Backend: Node.js, Express
	•	Database: MongoDB 
	•	Authentication: JWT
	•	Deployment: Vercel (Frontend), Render (Backend)
